# Linux Server Permission Management

## Objective
Implement group-based access control on Linux using users, groups, ownership, and permissions.

## Users
- Alice: devteam
- Bob: secureteam

## Access Rules
- devteam can access shared development files.
- secureteam can access confidential files.
- Unauthorized users are denied access.

## Tools & Commands
- useradd
- groupadd
- usermod
- chown
- chmod
- id
- ls
- sudo

## Validation
Verified authorized access and permission-denied results for unauthorized users.
